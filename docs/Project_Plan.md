# Project Roadmap

## Phase 1: Dataset Exploration

- Download ClinVar dataset
- Extract CFTR variants
- Analyze variant distribution

## Phase 2: Data Preparation

- Create pathogenic and benign labels
- Remove uncertain variants
- Prepare training dataset

## Phase 3: Model Development

- Random Forest
- Logistic Regression
- XGBoost

## Phase 4: Explainable AI

- Feature importance analysis
- SHAP interpretation

## Phase 5: Integration

- Apply model to variants obtained from WXS pipeline
